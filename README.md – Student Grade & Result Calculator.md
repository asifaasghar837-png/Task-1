# Student Grade & Result Calculator

## About the Project

This is a simple **Student Grade & Result Calculator** made using Python.  
I created this project to practice the basic concepts of Python and understand how marks can be used to calculate a student's result.

The program asks the user to enter their name and marks in different subjects. It then calculates the total marks, percentage, grade, and shows whether the student has passed or failed.

## Features

The program can:

- Take the student's name
- Take marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Calculate grade
- Display Passed or Failed
- Validate entered marks
- Handle multiple students
- Find the student with the highest percentage

## Concepts Used

While making this project, I practiced:

- Variables
- Data Types
- Input and Output
- Operators
- Conditional Statements
- Loops
- Functions

## How the Program Works

First, the program asks for the student's name and marks in different subjects.

After entering the marks, the program calculates the total and percentage. Then, using `if`, `elif`, and `else`, it determines the student's grade and result.

The program also checks that the entered marks are valid.

## Multiple Students

I also added the option to enter information for multiple students. After entering their results, the program compares their percentages and displays the student who achieved the highest percentage.

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the Python file.
4. Run the program.
5. Enter the required information when asked.
